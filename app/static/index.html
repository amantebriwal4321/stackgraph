Stackgraph

Dependency questions, answered with the Cypher that produced them.

The corpus is a FalkorDB graph of public npm and PyPI packages. Answers use only nodes and edges in that graph. With no model key, a rule router picks the query.

Scout writes a blast radius signal onto tools other packages depend on. Advisor reads those signals when you ask what would break.

Ask a question. The query, the parameters, and the path show up here.
